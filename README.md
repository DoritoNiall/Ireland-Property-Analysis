# Ireland-Property-Analysis
Irish Property Analysis using primarily AirBnB listings Data with supporting data from the Irish Property Price Register website
# Irish Property & Airbnb Pricing Analysis 2026
**Course:** PGDip Applied Data Analytics (DkIT)  
**Research Topic:** Predictive modeling of property prices and Airbnb yields across the 26 counties of Ireland.

## 📊 Project Overview
This project investigates the relationship between short-term rental premiums (Airbnb) and long-term residential property values (PPR). It aims to determine if Airbnb density significantly influences local property pricing trends in Ireland.

## 🛠️ Data Sources
- **Inside Airbnb:** Crowdsourced dataset of Airbnb listings and reviews.
- **PPR 2025:** Official Residential Property Price Register of Ireland (61k+ records).
